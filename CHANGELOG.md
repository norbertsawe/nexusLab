# Changelog

## 0.4.0 — Unreleased

- Added eigenvalues, SVD pseudoinverses, rectangular least-squares solves, and
  integer matrix powers, with validation and bounded decomposition iterations.
- Added array slicing, `:` selection, context-sensitive `end`, and indexed
  assignment using MATLAB-style column-major indexing.
- Corrected matrix division and power semantics; added standard square and
  rectangular array constructors and dimension-specific `size`.
- Added NexusAcademy with nine lessons, fifteen independently runnable
  examples, a contents tree, syntax highlighting, and a command reference.
- Added a custom SVG application mark, native window icons, multi-resolution
  Windows executable icons, and executable version information.
- Refined Windows toolbars, keyboard-accessible vector buttons, panel menus,
  and the empty workspace. The Tutorial panel supports native detachment and
  participates in layout recovery and close-all.

See [numerical compatibility](docs/compatibility.md) for migration notes and
the supported language subset.

## 0.3.0

- Published the Windows portable workbench with script editing, a command
  window, workspace editing, figures, DSP tools, hardware acquisition,
  light/dark preferences, and detachable native panels.
